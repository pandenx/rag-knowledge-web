# 踩坑日志（docs/error-log.md）

> 用途：记录项目开发中遇到的 Bug、报错、解决方案。
> 既是排查记录，也是**面试核心素材**——面试官最爱问"项目里遇到什么问题、怎么解决"。
> 规则：单 Bug 攻坚超过 30 分钟仍未解决，必须在此记录，然后暂停，次日再处理。

---

## 记录格式

```
### [日期] 问题简述
- **现象**：报错信息 / 异常表现
- **排查过程**：尝试了哪些方案、查了什么资料
- **根因**：最终定位的原因
- **解决方案**：如何修复
- **经验**：下次如何避免 / 面试如何讲
- **状态**：待处理 / 已解决
```

## 常见踩坑点（预告，开发时重点留意）

| 模块 | 常见坑 |
| --- | --- |
| SSE 长连接 | 客户端断开后后台请求未终止 → 内存泄漏；需监听 close 事件手动取消 LLM 请求 |
| 跨域 CORS | 前端、后端端口不同，未配置 CORS 导致浏览器拦截；需在 main.ts 配置 |
| PDF 解析 | 加密/损坏 PDF 抛异常；需捕获并返回前端友好错误；大 PDF 超时 |
| Embedding 限流 | 批量向量化触发接口限流；需做并发控制、重试、本地缓存 |
| Chroma | 版本兼容、集合不存在报错；启动顺序问题 |
| Docker | 容器文件权限、sqlite 持久化、容器间网络不通 |
| TypeORM | 实体与表映射错误、sqlite 文件路径问题 |
